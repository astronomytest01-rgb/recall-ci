# Recall

Локальное iOS-приложение, чтобы учить и повторять свою базу знаний. Работает без интернета и без аккаунтов, прогресс хранится только на телефоне.

Контент разложен по пакам. Пак — это JSON с вопросами, собранный из Markdown любого репозитория. В приложение встроен пак «Как учиться с Recall», остальные собираются из своих заметок.

## Что внутри

- **Сегодня.** Ежедневная тренировка по интервальному повторению (SM-2): карточки, которые пора повторить, плюс порция новых. Есть стрик по дням, цель дня и слабые темы.
- **Темы.** Паки сгруппированы по репозиториям. Каждую тему можно пройти тестом, прогнать целиком или открыть как шпаргалку. Поиск идёт по всем вопросам и ответам.
- **Вопросы.** Два типа. Выбор ответа: после правильного можно нажать «Угадал», тогда карточка вернётся раньше. Карточка «вспомни»: сначала показываешь ответ, потом сам оцениваешь, насколько помнил. Ошибки возвращаются ещё раз в той же сессии, в конце показывается разбор.
- **Блиц.** Экспериментальный режим, ниже о нём подробнее.
- **Настройки.** Тема (системная, светлая, тёмная), цель дня, сколько новых карточек в день, ежедневное напоминание, какие паки включать в тренировку, импорт паков, сброс прогресса.

## Блиц (эксперимент)

За 60 секунд нужно ответить на как можно больше вопросов. Каждый показан с одним вариантом ответа: верный свайпаешь вправо, неверный влево. Серия без ошибок даёт множитель ×2 и ×3. Интервалы повторения блиц не трогает, но засчитывается в стрик.

Зачем он нужен: на полную тренировку не всегда есть пять минут. Блиц даёт короткий заход, который тоже держит стрик.
Что он должен поднять: число дней с занятиями в неделю и длину стрика.
Как проверить: сравнить `progress.json` за две недели с блицем и за две недели без него, по числу дней с ответами и среднему стрику. Если дней с занятиями не стало больше, режим убираем.

## Сборка и запуск

Нужны Xcode 16+ и XcodeGen (`brew install xcodegen`).

```bash
xcodegen generate
```

```bash
open Recall.xcodeproj
```

### На свой iPhone

1. Подключи iPhone кабелем. На телефоне включи «Настройки → Конфиденциальность и безопасность → Режим разработчика».
2. В Xcode: `Settings → Accounts`, добавь свой Apple ID. Хватит бесплатного.
3. Выбери таргет Recall → `Signing & Capabilities` → Team: свой Personal Team. Если bundle id `local.recall.app` занят, поменяй его на любой свой.
4. Выбери iPhone в списке устройств и нажми Run (⌘R).
5. На телефоне: «Настройки → Основные → VPN и управление устройством», доверься своему сертификату.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить из Xcode тем же Run. Прогресс при этом сохраняется. С платным аккаунтом разработчика срок — год.

### Тесты

```bash
xcodebuild test -project Recall.xcodeproj -scheme Recall -destination 'platform=iOS Simulator,name=iPhone 17'
```

Юнит-тесты проверяют расписание повторений, сессию и все встроенные паки. UI-тест `WalkthroughTests` проходит все экраны в светлой и тёмной теме и прикладывает скриншоты к результату. GitHub Actions (`.github/workflows/ios.yml`) собирает приложение под iPhone без подписи, гоняет тесты на симуляторе и выкладывает скриншоты артефактом `screenshots`.

## Как добавить другой репозиторий

Формат паков описан в [`tools/PACK_FORMAT.md`](tools/PACK_FORMAT.md). Самый простой путь — открыть Claude Code в этой папке и попросить:

> Сделай пак из ~/путь/к/репо

Скилл [`make-pack`](.claude/skills/make-pack/SKILL.md) прочитает Markdown, раскидает работу по субагентам, соберёт JSON и проверит его. Готовый пак кладётся одним из двух способов:

- в `Recall/Packs/` и пересобрать приложение, тогда пак будет встроен;
- через AirDrop или «Файлы» на телефон, затем «Настройки → Импортировать пак». Пересборка не нужна.

Пак с тем же `id` заменяет старый. Прогресс привязан к `id` карточек, поэтому при перегенерации их лучше не менять.

Проверка паков:

```bash
python3 tools/validate_packs.py Recall/Packs/*.json
```

## Устройство

- SwiftUI, iOS 17+, `@Observable`, без внешних зависимостей.
- `Recall/Model`: паки, интервальное повторение, сессия, хранилище (`progress.json` в Documents).
- `Recall/Views`: экраны и визуальный язык. В светлой теме тёплая «бумага», в тёмной тёплый графит. Вопросы набраны засечками, у кнопок тактильная тень. Ориентиры из Mobbin: Vocabulary, Speak, Brilliant.
- Параметры запуска для скриншотов: `-demo` заполняет приложение правдоподобным прогрессом, `-tab N` открывает нужную вкладку.
